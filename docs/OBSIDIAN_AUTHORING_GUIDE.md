# 📖 Obsidian で作る 8bit レトロノベルゲーム執筆ガイド

このガイドでは、**Obsidian（PC / スマホアプリ）を使って自分だけのテキストアドベンチャーゲームを作成・編集する手順と記法**をわかりやすく解説します。

---

## 🚀 1. ゲーム作成の基本の流れ

1. **Vault（保管庫）を準備する**
   - このプロジェクトの `vaults/` 配下に新しいフォルダ（例: `vaults/my_story`）を作ります。
   - Obsidian アプリを起動し、「保管庫としてフォルダを開く (Open folder as vault)」でそのフォルダを開きます。

2. **Obsidian で `.md` ファイルを書く**
   - 好きなタイトルで Markdown ファイルを作成します（例: `entrance.md`, `room1.md`）。

3. **ブラウザで遊ぶ**
   - ゲームの初期画面で **`1. 🏠 PROJECT VAULTS`** から作成した Vault を選ぶだけで、すぐに遊ぶことができます！

---

## ✍️ 2. Obsidian 拡張記法リファレンス

標準の Markdown に加え、以下の**「Obsidianネイティブな美しい記法」**を使うことで、プログラミング不要でインタラクティブなゲームを構築できます。

### ① シーンの基本情報 (Frontmatter)
ファイルの先頭に以下のように書くことで、シーンタイトルや背景BGMを指定できます。
`start: true` を記述すると、そのファイルが**スタート画面（最初のページ）**として優先読み込みされます！

```markdown
---
title: 朝のカフェ
bgm: rain_sound.mp3
image: images/cafe.jpg
start: true
---
```

---

### ② 選択肢と移動 (WikiLink 記法)
Obsidian 標準の内部リンク `[[...]]` を書くだけで自動的に選択肢になります。

#### A. 別のシーン（別ファイル）に移動する
`[[遷移先ファイル名|表示ボタン名]]`

```markdown
[[living|居間へ入る]]
[[garden|庭へ出る]]
```

#### B. 画面を変えずに「同一ファイル内で詳しく調べる」（セクション移動）
Obsidian 標準の見出しリンク `[[#見出し名|表示ボタン名]]` を使います。別ファイルへ移動せず、画面のままそのセクションの文字が表示されます！

```markdown
部屋の中を見渡す。

[[#棚|棚を調べる]]
[[#窓|窓の外を見る]]

## 棚
棚には古びた文庫本が並んでいる。

[[entrance|元の場所に戻る]]
```

---

### ③ 条件付き選択肢 `(if: 条件)`
特定アイテムや記憶を持っているかどうかに応じて、選択肢の表示・非表示を制御できます。
リンクの後に `(if: 条件)` を添えるだけです！

* **持っている時だけ表示**: `[[#箪笥|箪笥を開ける]] (if: brass_key)`
* **持っていない時だけ表示**: `[[#引き出し|引き出しを開ける]] (if: !brass_key)`
* **複数条件（AND条件）**: `[[#小箱|小箱を開ける]] (if: journal, wooden_box, !letter)`

```markdown
### [[#箪笥調べる|部屋の隅の小さな箪笥を試す]] (if: !brass_key)

### [[#箪笥開ける|真鍮の鍵で箪笥を開ける]] (if: brass_key, !old_journal)
```

---

### ④ アイテム・記憶の獲得 (`+`)
見出しセクションの文章の中に `+ item: アイテムID` または `+ memory: 記憶ID` と書くだけで、その文章を読んだ瞬間に獲得され、サイドバーに記録されます！

```markdown
## 下駄箱
+ item: brass_key
下駄箱の隅にある小さな引き出しを開けると、奥から古びた真鍮の鍵が出てきた！
```

---

### ⑤ 条件分岐 (`@ フラグ名`)
特定フラグ（記憶やアイテム）を持っているかどうかに応じて、地の文や展開を変化させます。

```markdown
@ memory:shoes
土間に残された靴は、かつて誰かが急いでここを立ち去った痕跡のように見えた。

@ default
土間には静けさだけが漂っている。
```

---

### ⑥ 情報の解凍・ブラー演出 (`==フラグ名|テキスト==`)
フラグ（記憶やアイテム）を獲得するまで、文字がぼやかされる演出です。

```markdown
==memory:shoes|この靴のサイズは、確かに祖父のものだったはずだ。==
```

---

## 📋 3. マスター目録 `master.md` の書き方

Vault の直下に `master.md` を置くことで、サイドバーに表示されるアイテムや記憶の全一覧を定義できます。

```markdown
# My Story: Master Index

## Objects
- brass_key: 真鍮の小さな鍵
- old_journal: 古びた日記帳

## Memories
- memory:shoes: 置き去りにされた革靴
- memory:incense: 祖父の焚いていた線香
```

---

## 💡 まとめ
Obsidian の標準的な内部リンク `[[移動先|ラベル]]` と簡潔な `(if: 条件)` を組み合わせるだけで、自由自在にフラグ管理・選択肢制御が行えます！
