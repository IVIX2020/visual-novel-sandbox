# 📖 Obsidian で作る 8bit レトロノベルゲーム執筆・文法マニュアル

このマニュアルでは、**Obsidian（PC / スマホアプリ）を使ってノーコードで8bit風レトロアドベンチャーゲーム（ビジュアルノベル）を執筆・編集するための文法・記法**を解説します。

Obsidian 純正の標準Markdown記法（Callout、タスクリスト、内部リンク `[[...]]`、引用 `>`、ハイライト `==...==`）をそのまま活かした書きやすいシンタックスになっています。

---

## 🚀 1. ゲーム作成の基本

1. **Vault（保管庫）を準備する**
   * このプロジェクトの `vaults/` 配下に新しいフォルダ（例: `vaults/the_house`）を作ります。
   * Obsidian アプリの「保管庫としてフォルダを開く (Open folder as vault)」で開きます。

2. **Obsidian で `.md` ノートを作成する**
   * 好きなタイトルで Markdown ノートを作成します（例: `entrance.md`, `living.md`）。

---

## ✍️ 2. Obsidian ゲーム文法リファレンス

### ① シーン情報 (Frontmatter)
ノートの先頭にメタデータを記述します。`start: true` を付与したファイルがゲーム開始時の最初のページになります。

```markdown
---
title: 玄関
bgm: ambient_rain.mp3
image: images/entrance.jpg
start: true
---
```

---

### ② 画像表示
画像の埋め込み記法を書くだけで、画面上の【VISUAL MONITOR】に背景画像が反映されます。

```markdown
![[images/entrance.jpg]]
```

---

### ③ 会話・心の声 (引用記法 `>`)
Obsidian の標準引用記法 `>` を使うと、キャラクターのセリフや内面の声として美しくスタイル表示されます。

```markdown
> 「静かな雨の日だ……土間の空気も冷たい」
```

---

### ④ 選択肢と移動 (WikiLink 記法 `[[...]]`)

* **A. 別のシーン（別ファイル）へ移動する**
  `- [[ファイル名|選択肢ボタン名]] (sfx:効果音名.mp3)`
  ```markdown
  - [[living|居間へ入る]] (sfx:door_open.mp3)
  - [[garden|庭へ出る]]
  ```

* **B. 同一ノート内で詳しく調べる（セクション移動）**
  見出し記法 `## 見出し名` と見出しリンク `[[#見出し名|選択肢ボタン名]]` を使います。別ファイルに遷移せず、画面上で調査・会話が行えます。
  ```markdown
  - [[#靴|土間の靴を見る]]
  - [[#下駄箱|下駄箱の引き出しを開ける]]

  ## 靴
  土間に一足の使い古された革靴が残されている。
  [[entrance|玄関に戻る]]

  ## 下駄箱
  古びた真鍮の鍵を見つけた。
  [[entrance|玄関に戻る]]
  ```

---

### ⑤ 条件付き選択肢 (Obsidian タスク記法 `- [条件]`)
Obsidian のタスクリスト記法 `- [条件]` を使うことで、特定の鍵や記憶を持っている（または持っていない）時だけ出現する選択肢を表現できます。

* **持っていない時だけ表示 (`!` 条件)**:
  ```markdown
  - [!brass_key] [[#下駄箱|下駄箱の引き出しを開ける]]
  ```
* **持っている時だけ表示**:
  ```markdown
  - [brass_key] [[#箪笥開ける|真鍮の鍵で箪笥を開ける]]
  ```
* **複合条件 (AND条件)**:
  ```markdown
  - [brass_key, !old_journal] [[#箪笥開ける|真鍮の鍵で箪笥を開ける]]
  - [old_journal, wooden_box, !taiwan_letter] [[#小箱解読|日記と小箱を組み合わせる]]
  ```

---

### ⑥ アイテム入手・記憶解放 (Obsidian Callout 記法 `> [!item]` / `> [!memory]`)
Obsidian の標準 Callout 記法を使うことで、画面上に8bitレトロカードとして美しくダイアログが表示され、同時にサイドバーの「OBJECTS」や「MEMORIES」領域にリアルタイムで解凍・獲得されます！

* **アイテム獲得 (`> [!item] キー名`)**:
  ```markdown
  > [!item] brass_key
  > 下駄箱の隅から古びた真鍮の鍵が出てきた！
  ```

* **記憶解凍 (`> [!memory] キー名`)**:
  ```markdown
  > [!memory] shoes
  > 土間に一足の使い古された革靴が残されている。かかとが擦り減っている。
  ```

---

### ⑦ テキスト解凍・ブラー演出 (`==#キー名 テキスト==`)
Obsidian のハイライト記法 `==...==` を使うと、対応する記憶やアイテムを獲得するまでは文章がぼかされ（`?????`）、獲得した瞬間に文字が鮮やかに解凍される演出になります！

```markdown
==#shoes この靴のサイズは、確かに祖父のものだったはずだ。==
==#journal_content 箪笥の奥から見つかった日記には、祖父が誰かを待ち続けていた記録が残されていた。==
```

---

## 📋 3. マスター目録 `master.md` の書き方

Vault 直下に `master.md` を作成すると、ゲーム画面右側の「OBJECTS」「MEMORIES」領域に全一覧（未獲得時は `?????`）が表示されます。

```markdown
# The House: Master Index

## Objects
- brass_key: 真鍮の小さな鍵
- old_journal: 革表紙の日記帳
- wooden_box: 桐の小箱
- taiwan_letter: 1947年の古い手紙

## Memories
- shoes: 置き去りにされた革靴
- incense: 祖父の焚いていた線香
- garden_secret: 庭の隅に眠る石碑
- journal_content: 日記に記された告白
- taiwan_truth: 1947年の約束
```

---

## 💡 まとめ
Obsidian のネイティブ記法（Callout、タスク `- [条件]`、WikiLink `[[...]]`、引用 `>`、ハイライト `==...==`）だけで、マークダウンを書く感覚で自然に美しいレトロノベルゲームが作成できます！
