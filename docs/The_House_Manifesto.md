# 記憶の家を、筆先から解凍する。──新プロジェクト『The House』始動

さて、一つの物語が、その「名前」を授かるところからすべては始まりました。

もともと『THE FOUR SEASONS』として動き出していたこのプロジェクト。親子三代、そして台湾と日本を繋ぐ壮大な物語の器として選ばれた新しい名は、**『The House』**。

美しくもどこか記号的だった「四季」という言葉を脱ぎ捨て、祖父が一生をかけて守り抜いた「家」そのものにフォーカスする。この改称は、単なるラベルの貼り替えではなく、物語の解像度を一気に引き上げる「儀式」のようなものでした。

そして今、この「家」を実際に歩き回り、隠された秘密を紐解くための**「Narrative Sandbox」**が完成しました。

今回は、これまでの歩みと、これから始まる「執筆という名の探索」について、少しお話しさせてください。

---

## 1. 執筆が、そのまま「世界」になる

このサンドボックスの最大の特徴は、**「Obsidian で書いた文字が、そのままゲームのロジックになる」** という点にあります。

あなたが Obsidian で「玄関」の描写を書き、そこから「居間」へのリンクを貼る。
それだけで、ブラウザ上の『The House』には新しい扉が生まれ、プレイヤーはそこを歩けるようになるのです。

「ゲームを作る」という高いハードルを、日々の「執筆」という慣れ親しんだ作業まで引き下ろすこと。それが、このサンドボックスの思想の核です。

## 2. 記憶を「解凍」する体験

『The House』は、ただの脱出ゲームではありません。これは**「認識の変容」**を描く物語です。

最初はただの「古い靴」に見えていたものが、ある事実を知った後では「逃亡の跡」に見えてくる。
その感覚をシステムとして実装しました。

*   **ぼやけた視界**: 条件を満たさないと読めない、CSSによる「文字のブラー」。
*   **動的な地の文**: フラグによって、同じ場所でも描写がガラリと変わる分岐システム。
*   **写真という遺品**: 画面の中に浮かび上がる、セピア色のポップアップ画像。

これらすべてが、Obsidian のシンプルな記法だけで制御されています。

## 3. これからの展望：蔵の中に眠る「南方の春」

ここからのフェーズは、いよいよこの「箱」に中身を詰めていく作業になります。

*   **台所、書斎、そして二階へ**: 家の構造を広げ、祖父の生活の痕跡を点在させる。
*   **「役」のパズル**: 花札の「役」が揃うことで、物理的に封印されていた「蔵」が拓かれる瞬間。
*   **台北の記憶**: 蔵の中に再現された、異国の居間。そこにある「種」が意味するもの。

筆を動かすたびに、家の霧が晴れていく。そんな魔法のような体験が、あなたを待っています。

## 4. テクニカル・リファレンス（保存版）

ここからは、実際に物語を紡いでいくあなた（そして私）のための備忘録です。

### ■ ディレクトリ構造と役割

| フォルダ/ファイル | 役割 |
| :--- | :--- |
| `_sandbox/data/` | **物語の本体。** ここにある `.md` ファイルが各部屋（シーン）になります。 |
| `_sandbox/data/master.md` | **秘密の目録。** オブジェクトや記憶の全リストをここで管理します。 |
| `_sandbox/public/assets/` | **視覚と聴覚。** 背景、写真、BGM、効果音をここに配置します。 |
| `_sandbox/index.html` | ゲームの骨組み。ブラウザでこれを開いて遊びます。 |

### ■ Obsidian で使える「魔法の記法」

| 記法 | 意味・動作 |
| :--- | :--- |
| `[[living\|居間へ]]` | **移動。** 指定したシーン（ファイル名）へ転送します。 |
| `### (memory:id\|ラベル)` | **調査。** 記憶をアンロックし、詳細テキストを表示します。 |
| `![[assets/image.jpg]]` | **画像。** 本文冒頭なら背景、見出し下ならポップアップになります。 |
| `@ flag_id` | **分岐。** そのフラグがある時だけ、以降の文章を表示します。 |
| `+ flag_id` | **フラグ設定。** その文章を読んだ瞬間にフラグが立ちます。 |
| `==id\|テキスト==` | **情報の解凍。** 条件を満たすまで、テキストをぼかします。 |
| `(sfx:file.mp3)` | **効果音。** ボタンを押した瞬間に音を鳴らします。 |
