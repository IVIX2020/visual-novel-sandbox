# The House: Narrative Design Manual (執筆者向け)

このドキュメントでは、Obsidian を使用して『The House』の物語、部屋、ギミックを構築する方法を説明します。コードを触る必要はありません。

---

## 1. クイックスタート：新しい部屋を作る

1. `_sandbox/data/` フォルダに新しい Markdown ファイル（例: `kitchen.md`）を作成します。
2. ファイルの先頭にタイトルを記述します。
3. 本文に描写を書き、リンクで他の部屋と繋ぎます。

```markdown
---
title: 台所
---

![[assets/kitchen_bg.jpg]]

古い油の匂いと、微かなカビの臭いが立ち込めている。

### [[living|居間に戻る]] (sfx:slide.wav)
襖を閉めて、居間へ戻る。
```

---

## 2. 執筆ルール（記法）

### ■ 移動と調査
- **移動**: `[[シーン名|ボタンのラベル]]`
  - Obsidian の内部リンクと同じです。シーン名はファイル名（拡張子なし）に対応します。
- **調査**: `### (memory:id|ボタンのラベル)`
  - その場を調べるアクションです。押すと詳細テキストが表示され、記憶がアンロックされます。

### ■ 画像と音
- **背景画像**: メインテキスト内に `![[assets/image.jpg]]`。
- **ポップアップ画像**: `###` 見出しのすぐ下に `![[assets/photo.jpg]]`。
- **効果音**: 見出しに `(sfx:file.wav)` を追記。
- **BGM**: フロントマターに `bgm: file.wav` を追記。

### ■ フラグと条件分岐
- **フラグを立てる**: 本文中に `+ flag_id` と書くと、その一節を読んだ瞬間にフラグが立ちます。
- **出現条件**: `### 選択肢 (if:flag_id)` と書くと、そのフラグがある時だけボタンが出ます。
- **テキストの分岐**:
  ```markdown
  @ !seen_it
  初めて見た時のテキスト
  
  @ seen_it
  二回目以降のテキスト
  ```

### ■ 情報の解凍（ぼやけ）
- **記法**: `==記憶ID|隠したいテキスト==`
  - 指定した記憶（Memory）をまだ持っていない場合、その文字はぼやけて読めません。

---

## 3. マスターデータの管理 (`data/master.md`)

ゲームに登場するすべての「オブジェクト」と「記憶」をこのファイルで定義します。ここに書いたものが、ゲーム画面のサイドバーに `?????` としてリストアップされます。

```markdown
# Objects
- id: 名前

# Memories
- id: 名前
```

---

## 4. 執筆のヒント
- **連鎖する心境の変化**: 庭で何かを見つけたフラグを使って、玄関（`entrance.md`）の `@ found_something` ブランチを書くことで、主人公の気づきを表現できます。
- **音の演出**: 静かなシーンでは BGM を消し、`###` の詳細テキストにだけ微かな環境音を乗せることで、集中力を演出できます。
