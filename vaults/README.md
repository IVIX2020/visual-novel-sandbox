# 📚 Obsidian Game Vaults

このフォルダ配下には、ゲームシナリオの保管庫（Vault）が配置されています。

完全な執筆ガイドは以下を参照してください：
- [Obsidian ゲーム執筆完全ガイド](../../docs/OBSIDIAN_AUTHORING_GUIDE.md)

## 🎮 収録されている保管庫
- `the_house/` — 『The House』(祖父の記憶と家)
- `cyber_tokyo/` — 『Cyber Tokyo 2099』(サイバーパンク)

## ✍️ 新しいゲームを作るには
1. この `vaults/` 内に新しいフォルダ（例: `vaults/my_story`）を作ります。
2. Obsidian でそのフォルダを開き、`entrance.md` や `master.md` を作成します。
3. Webゲームのトップ画面でその Vault を選択するとプレイできます！
