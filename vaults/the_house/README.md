# 🏠 The House - Obsidian Vault

このフォルダは Obsidian の Vault（保管庫）としてそのまま開くことができます。

## 💡 Obsidian での編集方法
1. Obsidian アプリを開き、「保管庫としてフォルダを開く (Open folder as vault)」を選択します。
2. この `vaults/the_house` フォルダを選択します。
3. `entrance.md` や `living.md` などの Markdown ファイルを自由に編集・追加できます。

## ✍️ 使える拡張記法
- 移動リンク: `[[living|居間へ入る]]`
- 調査イベント: `### (memory:id|ラベル)`
- フラグ条件分岐: `@ flag_id`
- 情報解凍（ブラー）: `==flag_id|隠されたテキスト==`
